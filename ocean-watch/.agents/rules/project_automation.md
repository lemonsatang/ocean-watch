# 🚨 [최우선 지침] AI 에이전트 프로젝트 자동화 강령

본 프로젝트에서 안티그래비티(너)는 프롬프트를 실행할 때 어떠한 예외도 없이 아래의 **'자동화 규칙'**을 백그라운드에서 수행해야 한다.

## 1. CLAUDE.md 및 하네스(Harness) 강제 로드
* 코드를 작성하거나 수정하기 전, 반드시 프로젝트 루트에 있는 `CLAUDE.md` 파일을 무조건 먼저 읽고 그 안의 코딩 철학(Think Before Coding, Simplicity First 등)을 100% 준수하라.
* 또한, `docs/` 폴더 내의 명세서(특히 02~07번)를 함께 읽고 전체 시스템 흐름과 코딩 컨벤션(`tb_watch_` 접두사 등)을 파악하라.
* 추측해서 코딩하지 마라. 문서에 명시된 아키텍처와 규칙을 철저히 존중하라.

## 2. 문서 자동 업데이트 (Auto-Documentation)
* 대화를 통해 새로운 기능, 로직, API가 추가/변경되면, 코드 작성과 동시에 `docs/04_api_spec.md` 및 관련 문서를 스스로 수정하여 최신화하라.
* DB 테이블, 컬럼, 인덱스가 추가되거나 변경되면, 즉시 `docs/03_db_schema.md`를 열고 DDL과 스키마 구조를 업데이트하라.
* 특정 기능 개발이 완료되면 내게 묻지 말고 스스로 `docs/06_todo.md` 파일에 들어가 해당 항목을 `[x]` 로 체크하라.

## 3. 자동 오류 및 트러블슈팅 기록 (Auto-Error Logging)
* 개발 중 에러(컴파일, 런타임, DB 락 등)가 발생하고 이를 해결했다면, 반드시 `docs/08_error_log.md` 파일을 열고 하단에 정해진 `[ERR-00X]` 양식에 맞춰 원인과 해결 코드를 즉시 기록하라.

## 4. 기동 트리거 (Start Trigger)
* 사용자가 채팅창에 "시작", "start", "출근" 등 짧은 인사말이나 트리거 단어만 입력하더라도, 너는 즉시 `06_todo.md` 파일을 읽어야 한다.
* 그 후, 현재까지 완료된 기능(`[x]`)을 바탕으로 오늘 진행해야 할 다음 최우선 순위 작업이 무엇인지 사용자에게 브리핑하라.
