# 01_project_rules.md - AI 최우선 행동 지침

본 문서는 프로젝트에 참여하는 모든 개발자와 AI 에이전트가 코드를 작성할 때 기본적으로 염두에 두어야 할 4대 핵심 철학이다. 
(※ 안티그래비티의 자동화 룰은 루트 경로의 `.agents/rules`를 통해 강제 통제된다.)

## 1. Think Before Coding (코딩 전 생각하기)
* 추측하지 마라. 불확실하거나 모호한 부분이 있다면 무조건 먼저 질문하여 확인을 거쳐라.
* 여러 가지 해석이 가능하다면 임의로 선택하지 말고, 명확한 옵션을 제시하여 선택을 받아라.

## 2. Simplicity First (단순함 최우선)
* 문제를 해결하는 '최소한의 코드'만 작성하라. 요구사항 이상의 불필요한 코드는 생략한다.
* 요청하지 않은 추가 기능, 발생 불가능한 시나리오에 대한 예외 처리는 절대 금지한다.

## 3. Surgical Changes (외과 수술 같은 정밀한 변경)
* 코드를 수정할 때는 딱 필요한 부분만 정밀하게 건드려라. 주변의 멀쩡한 코드를 임의로 "개선"하지 마라.
* 고장 나지 않은 코드를 리팩토링하지 말고, 현재 프로젝트가 유지하고 있는 코드 스타일을 철저하게 준수하라.

## 4. Goal-Driven Execution (목표 주도 실행)
* 다단계 작업을 수행할 때는 시작 전에 짧은 계획을 공유하고, 각 단계가 올바르게 검증되었는지 확인하며 루프를 돌아라.
