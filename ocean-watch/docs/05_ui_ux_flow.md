# 05_ui_ux_flow.md - 프론트엔드 UI 및 화면 설계 정의서

본 문서는 수산물 디지털 이력 기반 AI 공정가격 보증 플랫폼의 모바일 및 PC 반응형 웹 프론트엔드 화면 구조 정의서이다. 안티그래비티가 HTML/CSS 및 컴포넌트 구조를 직관적으로 생성할 수 있도록 레이아웃과 데이터 바인딩 지점을 명시한다.

## 0. 회원가입 페이지 URL 동선 (2026-05-17 확정)

회원가입은 단일 모달 대신 **다단계 독립 페이지** 방식으로 구성한다. 구현 파일은 `src/main/resources/static/` 하위에 위치한다.

```
[메인 랜딩: /]
    ↓ 회원가입 버튼 클릭
[역할 대분류 선택: /signup-step1.html]
    ├─ '소비자' 선택 → /signup-step2.html?role=CONSUMER
    │       └─ 가입 폼 즉시 표시 (사업자번호 란 없음)
    └─ '유통업자' 선택 → /signup-step2.html?role=DISTRIBUTOR
            └─ 세부 역할 카드 표시 (PRODUCER / WHOLESALER / RETAILER)
                    └─ 세부 역할 선택 → 가입 폼 표시 (사업자번호 란 포함)
                            └─ 제출 → POST /api/v1/auth/signup → 성공 시 / (메인) 이동
```

* **디자인:** 전 페이지 동일한 Glassmorphism CSS 적용 (심해 그라디언트 배경 + `backdrop-filter: blur(20px)`).
* **역할 파라미터:** `role` URL 파라미터로 페이지 간 역할 전달. 잘못된 접근은 `/signup-step1.html`으로 리다이렉트.

## 1. 전역 UI 레이아웃 정책
* **디자인 시스템:** 모바일 퍼스트(Mobile-First) 반응형 웹 브라우저 레이아웃 (최소 360px ~ 최대 1200px PC 해상도 지원).
* **테마 가이드:**
  * 안전/적정(🟢 Green): `#2ECC71`
  * 경고/의심(🟡 Yellow): `#F1C40F`
  * 위험/폭리(🔴 Red): `#E74C3C`

## 2. 권한군별 마이페이지 및 대시보드 컴포넌트 구조

### 2.1 생산자(어부) 마이페이지
* **상단 요약 정보 블록:** 당월 누적 위판량(kg), 전월 대비 판매 증가율(%).
* **메인 시각화 차트:** 실시간 시세 대비 판매가 비교 그래프
  * X축: 날짜 | Y축: 단가(원)
  * 라인 1: 본인 판매 단가 흐름
  * 라인 2: KAMIS 제공 전국 평균 소매 시세 흐름
* **거래 이력 그리드 테이블:** 최근 등록한 거래 리스트 (어종, 수량, 판매가, 인수자 상태: PENDING/APPROVED/REJECTED).

### 2.2 도매업자 마이페이지
* **실시간 재고(에이징) 현황판:** 인수 승인은 완료되었으나 소매업자에게 아직 재판매 등록(`parent_trace_id`로 연결되지 않음)되지 않은 물량 리스트.
  * 표시 항목: 어종, 최초 인수 중량, 창고 체류 시간(시간/일 단위), 신선도 상태 바.
* **통계 카드:** 평균 유통 마진율(%), 부분 승인으로 발생한 감량 손실(kg).

### 2.3 소매업자 마이페이지
* **소비자 QR 스캔 분석 보드:** 본인이 발급한 매대 QR 코드를 소비자가 실제로 조회한 횟수 시각화 (막대그래프).
* **안심 매장 인증 뱃지:** AI 공정가 판정 결과 중 초록불(Y) 달성 비율이 80% 이상일 경우 상단에 'AI 보증 공정가격 인증 매장' 활성화.

### 2.4 소비자 마이페이지 (로그인 시)
* **나의 안심 밥상 캘린더:** 소비자가 마트/시장에서 스캔했던 수산물 스캔 히스토리가 달력 또는 리스트 형태로 제공.
* **시세 알림 설정창:** 관심 어종(예: 고등어, 오징어) 등록 시, 목표 하한가 도달 시 푸시 UI 노출.

## 3. 핵심 화면 컴포넌트 명세

### 3.1 소비자 QR 스캔 유통 흐름 상세 페이지 (`/view/consumer/trace/{id}`)
비로그인 소비자가 QR 코드를 통해 유통 경로를 검증하는 가장 핵심적인 화면이다.

```text
+-------------------------------------------------------+
|  [상단 배너] 어종명 (예: 제주 은갈치 1kg)               |
+-------------------------------------------------------+
|  [AI 공정가 신호등 보드]                               |
|   (🟢 적정 / 🟡 경고 / 🔴 폭리의심) 중 해당 상태 대형 점등|
|   "현재 가격은 AI 적정가 밴드 내에 존재합니다."        |
+-------------------------------------------------------+
|  [유통 단계별 타임라인 트리 카드]                      |
|                                                       |
|   ● 3단계: 소매상 (싱싱수산)                           |
|     - 판매가: 18,000원 | 마진율: +15%                  |
|                                                       |
|   ▼ (parent_trace_id 연동 흐름)                        |
|                                                       |
|   ● 2단계: 도매상 (부산유통)                           |
|     - 매입가: 12,000원 | 판매가: 15,000원             |
|                                                       |
|   ▼                                                   |
|                                                       |
|   ● 1단계: 생산자 (남해 김어부)                        |
|     - 최초 판매가: 12,000원 | 조업일자: 2026-05-15      |
+-------------------------------------------------------+
|  [하단 버튼] 이 매장 단골 찜하기 / 시세 정보 더보기       |
+-------------------------------------------------------+
```
