# 00_project_overview.md - 프로젝트 마스터 기획서

## 1. 프로젝트 개요
공공데이터와 AI 기반 가격 분석을 활용하여 수산물 유통 가격의 적정성을 검증하고, QR 기반 유통 이력을 소비자에게 제공하는 플랫폼이다.
* **형태:** PC 및 모바일 반응형 웹 페이지
* **외부 API:** KAMIS, 공공데이터 포털 (실시간 시세 비교용)

## 기술 스택
| 영역 | 기술 |
|------|------|
| Language | Java 17 |
| Framework | Spring Boot 3.x |
| Build Tool | Maven |
| ORM | MyBatis |
| Database | PostgreSQL (Supabase) |
| Security | Spring Security, BCrypt, JWT (자체 발급 및 검증)

## 2. 핵심 목표
* **수산물 유통 구조 투명화**
* **폭리 탐지 및 공정가격 판정**
* **QR 기반 소비자 조회 시스템 구축**
* **생산자/유통업자 신뢰 확보**
* **정책기관 데이터 기반 제공**

## 3. 핵심 기능

5. **소비자 QR 조회**

## 4. 회원 관리 및 권한 구조 (RBAC)
Supabase Auth를 기반으로 회원가입 및 로그인 기능을 구현하며, 가입 시 다음 5가지 역할군(Role) 중 하나를 부여받는다. (소비자는 비로그인 이용 가능)

1. **관리자 (Admin):** 시스템 관제, 종합 통계 대시보드, 감사 로그 추적.
2. **생산자 (어부):** 최초 거래 등록, 분할 판매 관리.
3. **도매업자:** 생산자 거래 인수/거절, 부분 승인(수량 정정), 소매업자에게 재판매 등록.
4. **소매업자:** 도매업자 거래 인수/거절, 최종 소비자용 QR 발급.
5. **소비자:** 비로그인 기반 QR 스캔 및 유통 이력 조회, 회원가입 시 마이페이지 기능 이용 가능.

## 5. 상세 기능 및 비즈니스 로직 명세

### 기능 1: 견고한 회원가입 및 로그인 (보안 및 유효성 검사)
* **유효성 검사:** Spring Boot의 `@Valid` 제너레이션을 활용하여 빈 값 제출을 원천 차단하고 형식 오류를 검증한다.
* **비밀번호 로직:** 프론트엔드에서 일차적으로 비밀번호와 비밀번호 확인 일치 여부를 검사하고, 백엔드 연동 시 Supabase Auth를 통해 안전하게 처리한다.
* **중복 체크:** 회원가입 폼에서 이메일(ID) 입력 시 비동기 API 호출을 통해 중복 가입 여부를 즉시 확인한다.
* **필수 입력 항목:** 이메일(ID), 비밀번호, 사용자명, 전화번호, 사업자등록번호(선택), 역할군 지정.

### 기능 2: 계층형 유통 이력 및 Trace ID 생성
* **트리 구조 계층화:** 상위 단계 거래의 `TRACE_ID`(UUID)를 하위 단계 거래가 `PARENT_TRACE_ID`로 참조하는 계층형 트리 구조를 형성한다.
* **분할 판매 지원:** 대량의 물량을 쪼개서 여러 명에게 분할 판매할 수 있도록 1:N 자식 노드 생성을 지원한다.

### 기능 3: 거래 승인 / 거절 / 부분 승인(수량 정정) 프로세스
* **승인 및 부분 승인:** 하위 업자가 물품 인수 시 현장 상태에 맞게 수량을 직접 수정하여 승인(수량 정정)할 수 있는 기능을 제공한다. 수정된 수량 기반으로 거래 데이터가 갱신된다.
* **거절 로직:** 도/소매업자가 거래를 거절할 경우, 해당 수산물 데이터 자체는 폐기되지 않으나 거절한 업자의 인수 대기 목록에서는 즉시 숨김(안 보이게) 처리된다. 거래 상태는 '거절'로 변경되어 상위 단계 판매자가 마이페이지에서 확인 후 재조치할 수 있다.

### 기능 4: AI 공정가격 판정 및 실시간 시세 비교
* **시세 데이터 확보:** KAMIS 및 공공데이터 포털 API를 연동하여 현재 시장 표준 시세 데이터를 실시간으로 가져온다.
* **AI 적정가 판정:** 입력된 판매가를 AI 적정가 밴드 및 실시간 시세와 비교하여 공정가 신호등 결과(`Y`: 적정, `W`: 경고, `N`: 폭리)를 실시간으로 판정하고 저장한다.

### 기능 5: 소비자 QR 코드 발급 및 고속 조회
* **QR 발급:** 소매업자가 최종 판매 등록을 완료하는 시점에 고유 UUID 기반의 동적 QR 코드를 생성한다.
* **유통 흐름 시각화:** 소비자가 QR 코드를 스캔하면 생산자 → 도매업자 → 소매업자로 이어지는 상세 유통 과정(단계별 매입/판매가, 마진율, 수량 변경 이력)과 AI 신호등 결과를 모바일 웹 화면에 즉시 시각화하여 제공한다.

### 기능 6: 권한별 고도화된 마이페이지 대시보드
* **생산자:** 월간/연간 위판(판매) 총량, 공공 시세 대비 나의 평균 판매가 비교 그래프, 단골 거래처(승인율 높은 도매업자) 통계.
* **도매업자:** 현재 창고 미판매 재고 현황 및 체류 시간(신선도 에이징 관리), 평균 유통 마진율(%), 수량 정정에 의한 손실률 통계.
* **소매업자:** 발급한 QR 코드의 소비자 실제 스캔(조회) 횟수, AI 공정가(초록불) 달성 뱃지 및 비율, 일일 매출 요약.
* **소비자:** 나의 안심 밥상 스캔 히스토리(QR 스캔 이력 모아보기), 관심 수산물 시세 알림 설정, '착한 가게' 단골 매장 찜하기.

### 기능 7: 관리자(Admin) 전용 관제 시스템
* **종합 통계 대시보드:** 기간별 플랫폼 전체 거래량, 비정상 마진(빨간불) 발생 비율, 어종별 유통 마진 추이를 한눈에 모니터링하는 대시보드 차트 제공.
* **감사 로그(Audit Log):** 업체 승인 이력, 회원 정보 변경, 시스템 주요 활동 이력을 데이터베이스에 기록하고 추적하는 기능.
